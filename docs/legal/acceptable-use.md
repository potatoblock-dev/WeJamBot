# 可接受使用政策

本工具用于**用户本人控制的微信账号**上的低频辅助操作。

## 允许

- 管理自己收到的消息：归档、检索、转发给自己
- 在自己控制的会话里做自动回复、关键词提醒
- 把微信消息接入自己的其他工具链（笔记、看板、监控面板）
- 个人效率类用途

## 禁止

- **批量营销 / 群发广告**：向大量不特定用户发送信息
- **垃圾信息 / 骚扰**：高频重复发送、骚扰他人
- **绕过平台规则**：规避微信的风控、封禁或频率限制
- **未经同意处理他人数据**：抓取他人聊天内容用于分析、画像、转售
- **任何违法用途**

## 推荐接入

- **个人微信群 / 需进群**：用 **Callus-Bridge GUI**（`WEJAM_TARGET=127.0.0.1:7701`，Xvfb + AT-SPI）。openclaw **不能**进个人群。
- **仅私聊、想少点界面**：可选 **openclaw 非 GUI**（`:7702`，ilink 扫码长轮询）。见 [Callus-Bridge docs/openclaw.md](https://github.com/baitang-bt/Callus-Bridge/blob/main/docs/openclaw.md)。

无论哪条路径都是个人号自动化，存在平台风控；群聊场景接受 GUI 路径的相应风险。

## 风险自负

无论 openclaw 还是 GUI 路径，使用者需要自行确认：

1. 你的使用方式符合微信的服务条款；
2. 账号可能因自动化或个人号 bot 接入受到平台限制，风险由使用者承担；
3. 误操作（发错消息、误点按钮）由使用者负责。

:::warning 关于误发
GUI 路径下服务内部有危险按钮黑名单（`退出 / 注销 / 清空 / 删除 / 撤回 / 解散`
一律拒绝点击）。自动回复**白名单**由你配置 ——
把真实会话加进白名单，就等于**真的替你在这个会话里说话**。
:::
