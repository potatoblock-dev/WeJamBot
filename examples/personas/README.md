# 人设示范包

| 目录 | 用途 |
|------|------|
| `default/` | 线上默认：微信群闲聊搭子（短句、跟群味、查本地知识库） |
| `template/` | 空白模板：按广场常见结构填空后，拷到 `data/personas/<id>/` 并在控制台启用 |

参考写法（结构借鉴，不搬运具体角色卡正文）：

- [玖帕喵 Prompt Market](https://jiupamiao.asia/) — Role / Task / Voice；群聊卡常见「短回复、不代用户发言」
- [FEAIA 社区](https://feaia.com/Frontpage/community.html) — 人设 Prompt 包分区
- 拟人化提示词常见骨架：规则 + 少量 Example（飞书/社区流传写法）

酒馆 PNG 角色卡不能直接导入；把 description / personality 精简成短句微信口吻后再贴进 `persona.txt`。
